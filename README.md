PALMFORGE is a GTA-style cover art maker: drop in your own photos, arrange them across multi-panel poster boards (quartet, stacked trilogy, skyline, marquee and more), pick a sunset/neon/heat/noir colour grade with film finishes, type a caption in big gradient lettering, and export a PNG in 1080×1080, 1080×1350 or 1920×1080 — all offline in the browser, zero dependencies.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
