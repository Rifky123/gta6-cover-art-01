# SUNGRID — multi-panel poster studio

SUNGRID turns your photos and a caption into multi-panel poster art with a Vice City sunset/neon grade, bold gradient lettering and print finishes, exported as PNG in 1080×1080, 1080×1350 and 1920×1080. Everything runs offline in desktop Chrome; photos never leave your machine.

## Run it

Serve the app locally (`node serve.ts`, then open http://localhost:8080), or build the entry output with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
