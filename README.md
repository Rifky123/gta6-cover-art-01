DUSKLINE is a multi-panel cover-art studio: drop in your own photos, pick one of six panel
cuts and six colour grades, reframe every crop by hand, and export a GTA-poster-style cover
with big gradient lettering as a PNG in the three common post sizes — all offline, in one
browser tab.

## Run it

Serve `app/` with any static server and open it in desktop Chrome, or hand the entry in:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`node serve.ts` serves `app/` locally at http://localhost:8080. Nothing is uploaded; photos
are read from your own machine.
