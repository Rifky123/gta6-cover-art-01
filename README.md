HEATSPLIT is a multi-panel cover-art studio that turns your own photos and a
caption into a GTA-style poster — pick a panel layout, drop photos in, drag to
reframe, roll to zoom, choose a sunset/neon/heat/noir grade with grain,
scanline, halftone and vignette finishes, and export a PNG at 1080×1080,
1080×1350 or 1920×1080.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Open `app/index.html` straight from disk or serve it with `node serve.ts`
(then http://localhost:8080). Everything runs offline in desktop Chrome —
no build step, no dependencies.
