# Boulevard Press

A GTA-style cover art maker that runs entirely in your browser: drop in your own photos, arrange them across multi-panel poster layouts, and export a sunset-neon cover with bold gradient lettering as a PNG. Nothing leaves your machine.

## Run it

Serve the app and open it in desktop Chrome:

```
node serve.ts
```

Then open http://localhost:8080. Load a photo (or the built-in samples), pick a layout, a colour grade and a vibe, edit the caption, and export:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The second command writes the entry bundle (`app/`, `screenshots/` and `dossier.json`) to the output directory.
