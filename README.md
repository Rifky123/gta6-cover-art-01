**Neonpalm** turns your photos and a caption into multi-panel GTA-style cover art — quartet, collage, stacked or banner layouts, sunset/neon grades, film finishes, and one-click PNG export in the three common post sizes. It runs fully offline: open `app/index.html` in desktop Chrome, drop in photos, export.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
